# @fuaran-ui/fuaran

Reserved convenience entry point for the Fuaran UI TypeScript implementation. It exports only a
`VERSION` constant; the substantive packages ship separately under the `@fuaran-ui/*` scope.

**Install the real packages instead:**

```sh
npm install @fuaran-ui/ui @fuaran-ui/ops @fuaran-ui/renderer
```

For the F# reference implementation, see [`fuaran-ui/fuaran-dotnet`](https://github.com/fuaran-ui/fuaran-dotnet).
